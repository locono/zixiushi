# 自修室 · zixiushi.com

一间隔屏自习室——**考公自修室** 与 **考研自修室** 双席并设。

这里汇总考公、考研的课程目录、笔记资料与更新日志，把散落各处的学习资源收拢到一页，打开就能学。

## 收录内容

- **考公课程目录**：公务员、国考省考、教师、事业、文职、三支、社工、英语、财会、司法
- **考研课程目录**：英语、数学、政治、管理类联考、专业课、笔试、冲刺、押题、复试
- **免费笔记群**：网盘群笔记资料随时取用
- **更新日志**：课程更新动态逐日记录
